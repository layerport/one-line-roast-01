## The roast

> My banking app texts me a six-digit code, then logs me out for taking too long to read the code it just sent.

One original line (109 characters) roasting the banking app — the daily app that
sends you its own login code and then punishes you for reading it.

## How to run it

```sh
python3 main.py
```

It writes the roast line to `/output/entry.txt` (or
`$MAKEFUN_OUTPUT_DIR/entry.txt` when that is set), with no trailing newline.
Python 3.13 standard library only, no network, fully deterministic — every run
writes the exact same bytes.
